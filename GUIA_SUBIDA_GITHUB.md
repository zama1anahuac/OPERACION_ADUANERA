# Subir el proyecto a GitHub desde cero

1. Descarga el archivo `AnMayab_Expediente_Digital_2_2_PDFS_GITHUB.zip`.
2. Descomprímelo. Verifica que `index.html` esté junto a `css/`, `js/` y `assets/`.
3. En GitHub crea un repositorio nuevo.
4. Usa **Add file → Upload files** y selecciona los archivos **descomprimidos**, no el ZIP. Puedes hacerlo en varios commits si la carga falla; respeta siempre la jerarquía de carpetas.
5. En **Settings → Pages**, elige **Deploy from a branch**, rama `main` y `/ (root)`. Guarda.
6. Comprueba búsqueda, Carta Porte PDF, certificación de origen, pedimento, COVE y documentos UVA.

Tamaño individual mayor en este proyecto: alrededor de 3 MB. El ZIP completo está por debajo de 25 MB, pero **subir el ZIP como único archivo no publica automáticamente una web**.

Antes de publicar, revisa que puedas distribuir los PDFs de terceros y las fotografías con firmas y nombres personales.
