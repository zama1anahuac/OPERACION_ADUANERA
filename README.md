# Expediente Aduanero Digital · AnMayab · Edición PDF 2.2

Sitio estático para GitHub Pages. Proyecto académico de importación de 100,000 bolígrafos BIC Clic Stic de Houston a Progreso y Mérida.

## Contenido

- **44 fichas técnicas** con 8 apartados cada una.
- **27 archivos descargados de Drive** incluidos localmente, más el modelo académico 09-A de revalidación del B/L.
- **7 evidencias UVA en PDF** y siete miniaturas de visualización WebP generadas desde los PDF (sin archivos PNG redundantes en el sitio).
- Visor PDF, descarga individual, búsqueda, filtros, galería interactiva, vínculos entre fichas y ruta logística.

## Publicar en GitHub Pages

1. Descomprime el ZIP en tu equipo.
2. Crea un repositorio nuevo de GitHub y sube **el contenido descomprimido**, no el ZIP. Debe quedar `index.html` en la raíz junto a las carpetas `assets/`, `css/` y `js/`.
3. Si la web de GitHub limita los archivos de un solo commit, arrastra las carpetas por etapas sin cambiar rutas.
4. En GitHub abre **Settings → Pages**, selecciona **Deploy from a branch → main → /(root)** y guarda.
5. Revisa la portada, la biblioteca, el documento Carta Porte, los documentos UVA PDF, COVE, pedimento A1 y B/L revalidado.

## Advertencias

Es una simulación académica. Los folios SIM, sellos, firmas y códigos ilustrativos no sustituyen la verificación por autoridades o terceros acreditados. El PDF del pedimento contiene datos incompatibles con la ficha principal de AnMayab; se conserva sin alterarlo para permitir la auditoría.

La factura comercial y el Packing List presentes en Drive siguen teniendo **3 MB** cada uno (superan la expectativa expresada de 2 MB, aunque están por debajo del límite individual de GitHub web). Se conservan originales. La carpeta de Drive también contiene un archivo `CARTA PORTE.png` anterior, que se omitió porque existe una versión PDF actualizada. Los archivos Word originales se conservan y cuentan con vista PDF de apoyo.

Revisa permisos de publicación de fotografías, firmas, nombres y documentos antes de hacer público el repositorio.
